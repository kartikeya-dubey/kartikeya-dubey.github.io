DexAI turns unstructured information into actions. Documents, conversations and messages become tasks, calendar events, reminders and memory that sticks.

LLM-based extraction, RAG, agentic workflows, tool calling, persistent memory and scheduled automation, across the web app and Telegram.

The principle: AI should not stop at generating an answer. It should understand context, invoke tools, persist state and execute the workflow.

The idea

Fourprinciples

Understand context.Documents, chats and your own memory, in one view.
Invoke tools.Calendar, extraction, MCP endpoint, plugins.
Persist state.Facts, rules and sessions that last.
Run the workflow.Reminders, alerts and summaries on a schedule.

System design

How itworks

1

Client tier

An installable web app and a Telegram bot. One agent serves both.

2

API tier

A backend service with a scheduler and an async task queue.

3

AI layer

Agents for extraction, memory and integrations, running on the user's own LLM key.

4

Persistence

A managed database for state and object storage for uploaded files.
