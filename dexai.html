— Turning unstructured information into actions

DexAI is a full-stack agentic productivity platform that transforms documents, conversations, and messages into structured tasks, calendar events, reminders, contexts and persistent knowledge.

It combines LLM-based information extraction, RAG, agentic workflows, tool calling, persistent memory, and scheduled automation across web and messaging interfaces.

The system is designed around a simple principle: AI should not stop at generating an answer — it should be able to understand context, invoke tools, persist state, and execute the resulting workflow.

What it does

Core Features

◆

Documents to Events

Upload a PDF, image or text. An AI agent reads it and drafts calendar events for you to review.

◆

Telegram Assistant

Ask about your day or add events by chat. The same agent powers the web app and Telegram.

◆

Conversation Memory

Remembers context across chats and summarises long conversations to stay fast.

◆

Bring Your Own LLM

Each user connects their own AI provider, so cost and model choice stay with them.

◆

Rules & Personal Memory

Learns your preferences and custom rules to improve extraction over time.

◆

Calendar & Integrations

Two-way Google Calendar sync, an MCP endpoint for external AI tools, and a plugin framework.

◆

Finance Module

Import broker statements, track holdings with live prices, and get an optional AI committee review.

◆

Fitness Coach

Personal plans, live workout chat, progress tracking and reminders, with consent and data controls.

Under the Hood

Engineering Challenges

Long conversations

Older messages are summarised so chats stay coherent without growing forever.

Seeing what agents do

Every agent run is traced, so behaviour and quality can be inspected and debugged.

One brain, many channels

The same agent logic serves the web app and Telegram.

Any LLM provider

Five providers work with users' own keys. Next: one clean interface with retries and fallback.

Running on free tiers

Servers sleep and databases pause. A keep-alive monitor with alerts keeps reminders reliable.

Friendly failures

Users see a simple message. Admins get one alert that clears itself on recovery, and actions retry automatically.
